# 文献发展历史探索规范

## 范围

- 覆盖研究对象的整体历史、主要分支及相关发展主线；重点和详略随用户问题确定。
- 默认从领域起源延伸至检索时可核实的重要进展；以论文为入口时，包含其发表后的发展。
- 明确主题边界、时间范围、检索日期和文献选择依据；用户指定范围时以其要求为准。

## 检索与证据

- 使用可访问的学术检索来源核实文献信息；记录主要检索来源、关键词及资料覆盖限制。
- 关键历史结论以原始论文或官方学术记录为依据；综述可用于发现线索和补充背景。
- 核对关键论文的标题、作者、年份及 DOI 或稳定来源链接；区分预印本与正式发表版本。
- 说明理论提出、方法发展、实验验证和后续扩展之间的关系；不得仅凭时间先后推断继承或影响。
- 对“首次”“奠基”“直接推动”等判断提供证据；有争议或无法核实的关系明确标注。
- 区分来源所述事实与 agent 的归纳判断；未取得全文时说明依据范围。
- 检索受限时说明缺口，不虚构论文、来源、检索过程或最新进展。

## 内容与深度

- 先用简短概览给出发展主线，再按阶段说明研究问题、关键进展、代表论文和阶段之间的联系。
- 交代主要分支的形成、分化或交汇；避免将相互独立的工作写成单一路线。
- 对关键论文提供标题、作者、年份、核心贡献、历史位置、与研究对象的关系及原文入口。
- 有目标论文时，说明其承接的工作、贡献及后续发展；无目标论文时，围绕主题组织。
- 概述检索时可核实的重要后续进展，并注明尚未解决的问题和资料缺口。
- 首次交付保持精简；只解释理解历史关系所必需的术语，不扩展为论文讲义。
- 通过原文链接和简短的阅读顺序建议帮助用户继续阅读。

## 呈现与问答

- 结果包括检索范围、发展脉络、关键文献和证据缺口；结构与篇幅随任务确定。
- 将结论与来源对应；发展脉络中的文献可链接到关键文献条目，再访问原文。
- 历史时间线可以辅助阅读；不得以图表替代必要的联系说明。
- 历史追问遵循 [AGENTS.md](AGENTS.md) 的对话与文件更新规则。
