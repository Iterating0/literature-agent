# History Literature Agent

用于梳理研究领域的发展历史、主要分支和关键论文之间的联系。

- [AGENTS.md](history%20literature%20agent/AGENTS.md)：任务边界与交付要求。
- [history.md](history%20literature%20agent/history.md)：检索、证据与内容规范。
- [template.html](history%20literature%20agent/template.html)：离线 HTML 风格模板。

## 示例

每个主题使用独立文件夹，以 `index.html` 为入口。下载后用浏览器打开，相关本地附件放在同一主题文件夹中。

- [Haldane 模型与拓扑能带](示例/history%20haldane/index.html)：文献发展史，附页面引用的三份讲义。
